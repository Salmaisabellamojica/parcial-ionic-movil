Requisitos previos

Para ejecutar el proyecto necesitas instalar:

Node.js

npm, incluido con Node.js.

Git

Visual Studio Code (recomendado).

Verifica las instalaciones con estos comandos:

node -v
npm -v
git --version

Instalación

1. Clonar el repositorio

git clone https://github.com/Salmaisabellamojica/parcial-ionic-movil.git

Reemplaza https://github.com/Salmaisabellamojica/parcial-ionic-movil.git por la dirección del repositorio en GitHub.

2. Entrar a la carpeta del proyecto

cd parcial-movil

3. Instalar las dependencias

npm install

Este comando instala las dependencias necesarias para ejecutar la aplicación.

Ejecutar el proyecto

Desde la carpeta parcial-movil, ejecuta:

npx ionic serve

Cuando el servidor termine de iniciar, abre en el navegador la dirección local que aparezca en la terminal. Normalmente es:

http://localhost:8100

Mantén la terminal abierta mientras utilizas la aplicación.
